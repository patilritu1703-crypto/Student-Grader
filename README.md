# Student Grade Calculator

## Description
A Python program that calculates student grades based on marks entered by the user.

## Objective
To practice Python conditional statements (`if`, `elif`, and `else`) and input validation.

## Technologies Used
- Python 3
- Visual Studio Code

## Grading Criteria
- 90–100: A+
- 80–89: A
- 70–79: B
- 60–69: C
- 40–59: D
- 0–39: F (Fail)

## Features
- Accepts the student's name and marks.
- Calculates the corresponding grade.
- Displays pass or fail status.
- Handles invalid marks and non-numeric input.

## How to Run
1. Install Python 3.
2. Open the project in Visual Studio Code.
3. Open the terminal in the project folder.
4. Run `python Student_Grader.py`.
5. Enter the requested information.

## Learning Outcome
This project demonstrates the use of conditional statements, user input, functions, and basic error handling in Python.
